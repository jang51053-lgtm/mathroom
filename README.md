# 백룸 수학 탈출

Three.js로 만든 3인칭 백룸 탐험 + 수학 퀴즈 호러 게임입니다.

넓은 백룸을 헤매며 빛나는 **책**을 찾아 수학 문제를 풀고, 열쇠를 모아 **탈출문**으로
빠져나가는 것이 목표입니다. 지도는 없습니다. 바닥의 화살표, 책의 소리, 그리고
기억에 의지해야 합니다.

## 구역

맵은 매번 새로 생성되며, 성격이 다른 다섯 종류의 구역이 복도로 이어집니다.

| 구역 | 특징 |
|---|---|
| 노란 복도 | 고전적인 백룸. 젖은 카펫, 웅웅대는 형광등 |
| 미로 | 좁고 어두운 통로가 얽힌 구역. 조명이 드물고 자주 깜빡임 |
| 기둥 홀 | 천장이 높고 기둥이 격자로 늘어선 넓은 공간 |
| 풀룸 | 흰 타일과 청록색 물. 물속에서는 이동이 느려집니다 |
| 레드존 | 붉은 비상등만 켜진 가장 어두운 구역 |

## 엔티티

- **선생님** — 복도를 순찰하다 시야에 들어오면 쫓아옵니다. 문제를 틀릴수록 추격 속도가 영구히 빨라집니다.
- **그것** — 첫 열쇠를 얻으면 깨어납니다. **당신이 보고 있는 동안에는 완전히 멈추고**, 시선을 돌린 순간에만 다가옵니다.
- **응시자** — 멀리 서서 바라봅니다. **쳐다보는 동안 공포가 차오르고**, 계속 보면 순간이동으로 거리를 좁힙니다. 시선을 돌리면 공포는 가라앉습니다.

## 긴박함 장치 (미니맵 대신)

미니맵을 없앤 대신, 위치와 위험을 다음으로 전달합니다.

- 화면 가장자리 **비네트** — 엔티티가 가까울수록 좁아지고, 추격 중에는 붉게 변합니다
- **심장박동** — 위험이 커질수록 빨라집니다
- **스테레오 음향** — 발소리, 책의 신호음, 문의 저주파음이 좌우 방향으로 들립니다
- **화면 노이즈와 이명** — 공포 수치에 비례해 짙어집니다
- 바닥의 **초록 화살표** — 탈출문 방향을 가리키는 유일한 길잡이

## 실행 방법

정적 파일뿐이라 빌드가 필요 없습니다. 다만 브라우저 보안 정책상 `index.html`을
더블클릭해 열면(`file://`) 상대 경로 스크립트가 로드되지 않으므로, 로컬 서버로 실행하세요.

```bash
npx serve .
```

그 다음 브라우저에서 `http://localhost:<port>` 로 접속합니다.
GitHub Pages 등 실제 호스팅에서는 이 문제가 없습니다.

## 조작

- 왼쪽 조이스틱 / WASD · 방향키: 이동
- 화면 오른쪽 드래그: 시점 회전
- 오른쪽 하단 "달리기" 버튼 / Shift: 스프린트 (체력 소모)
- 책 탭 또는 E 키: 가까이 있을 때 문제풀이

## 프로젝트 구조

```
index.html        진입점, HUD 마크업
css/style.css     스타일, 비네트/노이즈 오버레이
js/level.js       타일 기반 구역 생성, 충돌·시야·경로탐색, 지오메트리 빌드
js/entities.js    엔티티와 소품의 절차적 메시
js/main.js        게임 루프, 플레이어, 카메라, 엔티티 AI, 오디오, HUD
assets/models/    (선택) 실제 3D 모델(.glb)
```

기술적으로는 맵 전체가 타일 격자 하나로 표현됩니다. 벽 충돌, 시야 판정, 카메라
충돌은 모두 격자를 직접 훑는 방식(DDA)이라 메시 레이캐스트 특유의 떨림이 없고,
렌더링은 구역별 `InstancedMesh` + 플레이어 주변으로 재배치되는 소수의 조명으로
처리해 넓은 맵에서도 60fps를 유지합니다.

## 실제 3D 에셋 교체

`js/main.js` 상단 `ASSET_PATHS` 경로에 `.glb` 파일을 넣으면 자동으로 플레이스홀더를
대체합니다. 코드 수정은 필요 없습니다.

| 대상 | 경로 |
|---|---|
| 주인공 | `assets/models/player.glb` |
| 선생님 | `assets/models/baldi.glb` |
| 책 | `assets/models/book.glb` |

- glTF Binary(.glb) 한 파일로 내보내세요.
- 정면은 +Z, 발밑은 y=0에 맞추면 별도 보정이 필요 없습니다.
- 크기·방향이 안 맞으면 `ASSET_TUNING`의 `scale`, `rotationY`, `yOffset`으로 조절합니다.
- `Walk` / `Idle` 애니메이션 클립이 있으면 자동으로 찾아 재생합니다.

## 난이도 조절

- `js/main.js` `CONFIG` 구역: 이동 속도, 엔티티 속도와 탐지 범위, 공포 증가율, 필요한 열쇠 수
- `js/level.js` 상단: 타일 크기, 맵 크기(`GW`/`GH`), 구역별 천장 높이·조명·안개
- `js/level.js`의 `plan` 배열: 각 구역 방의 개수와 크기
